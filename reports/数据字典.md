# SQLite 数据字典

所有时间沿用原始脱敏时间。NULL 表示缺失或明确不可估计，不代表 0。

## admissions

| 字段 | 类型 | 主键 | 含义 |
|---|---|---|---|
| subject_id | INTEGER |  | 脱敏患者标识；患者人数按此去重 |
| hadm_id | INTEGER | 是 | 脱敏住院标识；一次住院可含多次 ICU 入住 |
| admittime | TEXT |  | 医院入院时间（脱敏） |
| dischtime | TEXT |  | 医院出院时间（脱敏） |
| deathtime | TEXT |  | 住院记录的死亡时间（脱敏） |
| admission_type | TEXT |  | 医院入院类型 |
| admission_location | TEXT |  | 医院入院来源 |
| discharge_location | TEXT |  | 医院出院去向 |
| hospital_expire_flag | INTEGER |  | 医院住院死亡标记，不代表 ICU 内死亡 |
